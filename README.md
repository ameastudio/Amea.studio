Upload these files to the ROOT of your website repository:
- index.html
- styles.css
- script.js
- hero.png
- editorial.png

- argentina-lookbook.png

Then commit. If GitHub Pages is already set to `main` + `/(root)`, it will redeploy.

## Important before taking real orders
The package is the polished frontend. These need a secure backend/service connection before real commerce:
- Customer authentication/accounts
- Card payments
- Real order database and status tracking
- Automatic email confirmations
- Restock notifications
- Review uploads/moderation
- Cross-device favorites/bag sync
- Delivery pricing rules
- Website orders syncing to Améa HQ

Do not put secret API/service keys in a public GitHub repository.
